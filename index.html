按鍵與畫面佈局

點「編輯佈局」後，可拖曳方向鍵、A/B 鍵、SELECT/START，以及遊戲畫面本身來改變位置，並用右下角的綠色圖示縮放大小。設定會自動儲存在這台裝置的瀏覽器中，下次開啟網頁時會自動套用。

存檔

尚未載入卡帶

存檔會儲存目前的遊戲進度在這台裝置的瀏覽器中（每張卡帶各自保留一份最新存檔），關閉分頁或重新整理後仍會保留，但清除瀏覽器資料會遺失。鍵盤快捷鍵：F5 存檔、F9 讀檔。

連打 (Turbo)

開啟後，按住畫面上的 A 或 B 按鈕（或鍵盤 X / Z）會自動變成連續快速點擊，不需要一直手動按。

遊玩速度

倍速僅加快遊戲運行速度，音效在高倍速下可能會失真或省略，屬正常現象。

連線對戰（Link Cable）

尚未連線

建立房間後會產生一組 4 位數房號，把房號告訴另一位玩家；對方在上方欄位輸入相同房號並按下「加入房間」即可連線。連線成功後，兩邊模擬器的通訊埠（連線對戰、交換等遊戲內建功能）會互相中繼傳輸資料。此連線方式為簡化封包中繼，非逐位元精確時序模擬，多數常見的連線對戰/交換小遊戲可正常運作，但無法保證所有遊戲都相容。

已知限制

這是一個從零手寫、單一 HTML 檔案的簡化 GB/GBC 模擬器核心：支援 MBC0 / MBC1 / MBC3（無精確 RTC 計時） / MBC5 卡匣、CPU 全指令集、背景＋視窗＋精靈繪圖、CGB 調色盤，並包含四聲道音效（方波 x2、波形聲道、雜訊聲道）。 目前不支援雙倍速 CGB 模式、不支援 MBC2/MBC6/MBC7 等少見卡匣，掃描線繪圖為近似時序，部分依賴精確中掃描線效果的遊戲畫面可能不正確。多數常見的 GB / GBC 遊戲可以執行，但無法保證每一款都能完美相容。
